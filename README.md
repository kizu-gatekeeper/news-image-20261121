Entry for make.fun `news-image-20261121`: sum up the world's news of
Saturday 21 November 2026 in one image.

The image is a front page drawn for the day: the lead story is Russia's
massive overnight strike on Kyiv (400+ drones, 110 missiles) with missiles
also landing in Poland; then the AI sell-off that pushed Wall Street into
correction, the World Court's genocide finding against Myanmar, the
Trump–Xi–Putin peace declaration from Shenzhen, and the COP31 deadlock in
Antalya — plus an "Also today" strip and a markets ticker.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `/output/entry.png`. Run locally with:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
